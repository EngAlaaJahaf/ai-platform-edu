# منصة ذكاء | EduAI — المساعد الأكاديمي الذكي 🚀

منصة ذكاء اصطناعي متكاملة (Production-Ready) مخصصة للطلاب والباحثين الجامعيين، تجمع بين تقنيات **الاسترجاع المعزز بالتوليد (RAG)**، والتلخيص الهيكلي، وتوليد الخرائط الذهنية، ومولد الاختبارات التفاعلي، والتدقيق الأكاديمي.

---

## 🌟 المميزات الرئيسية

1. 💬 **المحادثة الذكية التوثيقية (RAG Chat):**
   - استيعاب وفهرسة ملفات الـ PDF تلقائياً مع تجزئة ذكية (Chunking).
   - إجابات دقيقة موثقة برقم الصفحة والاقتباس المباشر.
   - كشف تلقائي وتنبيه للأسئلة خارج نطاق الملف لمنع الهلوسة.

2. 📑 **الملخص الذكي والخريطة الذهنية:**
   - 3 مستويات تلخيص: (سريع - متكامل - عميق).
   - استخراج المفاهيم والتعريفات المحورية.
   - خريطة ذهنية تفاعلية حية (SVG) قابلة للتكبير والتحميل.
   - تصدير بصيغ Markdown والطباعة المباشرة.

3. 🎯 **استوديو الاختبارات وتنبؤ الأداء (Exam Engine):**
   - توليد أسئلة اختيار من متعدد (MCQ) متوازنة بمستويات صعوبة متعددة.
   - تصحيح فوري وشرح تفصيلي لكل خيار.
   - وضع بطاقات الاستذكار (Flashcards) لتعزيز الذاكرة والاسترجاع النشط.
   - تحليل ذكي وتنبؤ بدرجة الامتحان بناءً على مستوى الإجابات.

4. ✍️ **التدقيق والأصالة الأكاديمية (Proofreader & Paraphrasing):**
   - كشف الأخطاء الإملائية والنحوية والأسلوبية مع تطبيق التصحيح بنقرة زر.
   - قياس نسبة الأصالة الأكاديمية (Originality Score).
   - اقتراحات إعادة الصياغة الأكاديمية الفصيحة.

5. 📊 **لوحة تحكم الطالب (Student Dashboard):**
   - خطة مراجعة ذكية لمدة 3 أيام.
   - مكتبة المقررات والملفات النشطة.
   - رابط تصويت المعرض لمشروع #07.

---

## 🛠️ المعمارية والتقنيات المستخدمة

- **الواجهة الأمامية (Frontend):**
  - React 19 + Vite 6
  - Tailwind CSS v4 + Lucide Icons + Canvas Confetti
  - خطوط عربية فاخرة: Tajawal & IBM Plex Sans Arabic
  - واجهة RTL داكنة متجاوبة 100% مع تأثيرات Glassmorphism

- **الواجهة الخلفية (Backend & AI Engine):**
  - Python 3.11 + FastAPI + Uvicorn
  - معالجة الـ PDF: PyMuPDF (fitz)
  - محرك الـ RAG والبحث الدلالي: RAG Semantic Vector Retrieval Engine
  - الذكاء الاصطناعي: Google Gemini 1.5/2.0 API + محرك ذكاء محلي احتياطي عند غياب المفتاح.

## 🚀 طريقة التشغيل السريعة

### 1. بنقرة واحدة (Windows):
قم بتشغيل ملف `run_dev.bat` وسيقوم تلقائياً بتشغيل الباك إند والفرونت إند معاً:
```bash
run_dev.bat
```

### 2. يدوياً:
- **تشغيل الباك إند:**
```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8001 --reload
```

- **تشغيل الفرونت إند:**
```bash
cd frontend
npm run dev
```

افتح المتصفح على: `http://localhost:5173`

## 🔑 إعداد مفتاح Gemini API (اختياري)

أنشئ ملف `.env` في المسار الرئيسي وضع فيه المفتاح:
```env
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-1.5-flash
PORT=8001
```
*(إذا لم يتم وضع المفتاح، سيعمل التطبيق في وضع الذكاء المحلي الذكي لتقديم تجربة عرض سلسة ومكتملة).*
