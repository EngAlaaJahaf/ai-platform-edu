# نماذج الواجهة المقترحة — «دراسة هادئة»

ملف واحد معاينة للتصميم المستهدف قبل التنفيذ في المشروع الفعلي (`docs/ui-mockups/index.html`).

- افتح الملف مباشرة في المتصفح (لا يحتاج بناء أو خادم).
- تنقّل بين الشاشات من الشريط العلوي (النظام · اللوحة · المحادثة · الاختبار · الملخص · الترجمة).
- بدّل الفاتح/الداكن بنقرة واحدة، وشغّل «هاتف» لمعاينة الاستجابة على عرض ٣٩٠px.
- النماذج للموافقة عليها فقط؛ المواصفات المعتمدة تقود التنفيذ الفعلي عبر مهارة `eduai-phase4-ux-redesign`.
